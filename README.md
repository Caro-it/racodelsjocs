# 🎮 El Racó dels Jocs

Portal de jocs per a infants en català, amb estil kawaii.
Sense anuncis · Sense compres · Sense comptes ni dades personals.

## Jocs
- 🏨 Hotel Estrelleta – rep hostes i fes créixer el teu hotel
- 👗 Vestidor Màgic – pentinats, roba, mascotes i reptes
- 🧺 La Botigueta – cultiva, omple prestatges i cobra als clients
- 🧩 Blocs Dolços – encaixa peces i completa files
- 🃏 Memòria Kawaii – troba les parelles
- 🌠 Atrapa Estrelles – atrapa estrelles amb el núvol

## Tecnologia
HTML, CSS i JavaScript (Canvas), en un sol fitxer.
Les partides es guarden només al dispositiu (localStorage).

👉 Juga-hi: https://caro-it.github.io/racodelsjocs/
